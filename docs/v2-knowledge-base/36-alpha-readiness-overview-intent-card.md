# 意图卡：单品牌 DeepSeek Alpha 上线就绪总览 V1

状态：Gate A-F 已通过并封版
日期：2026-09-15

## 目标

把已封版模块、真实运行证据、上线前置条件和明确阻塞集中成一页可读总览，帮助业务负责人判断“能否进入单品牌真实试运行”，而不是继续按业务细节拆分 Gate。

## 自动汇总范围

- 已封版的品牌真相、问题组、DeepSeek API 采样、引用/信源、GEO 情报、诊断、监测、事实补充工作台；
- 本地测试、数据库/队列恢复、Web 构建和 GitHub Linux CI 证据；
- 阿里云部署、HTTPS、备份、日志、告警和域名等上线前置项；
- Alpha 明确不包含的多模型、多账号发布、Web/App 搜索终端和自动对外发布。

## 不可伪造的状态

- `ready`：有当前版本的可追溯证据；
- `pending`：尚未执行或尚未取得材料；
- `blocked`：受外部环境或主机策略阻断；
- `not_in_alpha`：明确不属于本次 Alpha。

总览不得将 `pending` 或 `blocked` 汇总成“已上线”，也不得把 DeepSeek API 结果描述为 Web/App 搜索表现。

## 下一步自动动作

1. 从知识库和当前验收接口生成状态矩阵；
2. 对每个 `pending/blocked` 项给出最小解决路径和是否需要用户确认；
3. 仅在所有上线硬门槛满足后建议进入云端预发布；
4. 继续保留阿里云 `blocked-by-host-policy`，不要求用户重复执行技术命令。

## 非目标

- 不新增业务事实；
- 不自动修改阿里云现有业务；
- 不开放正式发布权限；
- 不把 Alpha 变成完整商业化版本。
