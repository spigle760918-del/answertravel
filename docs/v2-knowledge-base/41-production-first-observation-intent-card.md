1. 脚本默认只能运行 `dry-run`，不得写数据库或入队；
2. 真实执行必须同时提供 `--execute` 与固定授权标记；
3. 生产租户、已批准问题数、采样规则、计划样本数和 Token 上限任一不匹配即停止；
4. 首次执行前，生产观察计划、原始回答、周期计划和观察队列待处理任务必须为 0；
5. 计划 ID、周期键和 40 个目标的幂等键固定；中断后只允许对同一计划安全重跑，不允许静默创建第二个基线；

7. 真实入队前再次核对 Worker 已使用生产密钥且运行正常。
