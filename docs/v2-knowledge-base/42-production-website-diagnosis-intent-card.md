- 只访问北京珈程已确认官网 `https://www.jiacheng666.com/` 及同域名内固定公开页面；

- 生成不可变、租户隔离、版本化的诊断快照，并接入验收台与后续GEO差距复诊。

## 安全与证据边界

- 仅允许HTTP/HTTPS公开页面，固定域名白名单，执行DNS私网地址、重定向、内容类型、大小和超时门禁；

- 不把页面存在等同于模型已吸收，不把官网自述升级为第三方事实，不宣称页面问题造成当前品牌零提及；
- 不调用DeepSeek，不新增观察任务，不启动周期监测，不修改官网、Nginx、数据库中的品牌真相或任何公开内容；

## 验收标准

1. 每个目标页面均保存成功、失败或阻断状态及内容哈希；
2. 能明确展示已具备的主体/产品证据与缺失的机器可读结构、元数据或新鲜度信号；
3. 官网销量、满意度、低价和保障表达被标记为自述，不冒充独立证据；
4. 重复输入保持幂等，历史诊断不可覆盖，跨租户不可见；
5. GEO差距复诊能够识别网站证据已接入，但样本/周期不足时仍保持“先扩样”，不得被网站诊断绕过；
6. 验收台使用业务语言展示结果，发布权限固定为否。

## 非目标

- 不做全站无限爬取、竞品网站诊断、SEO排名、搜索收录或性能压测；
- 不生成或发布文章、FAQ、Schema或页面改版；
- 不自动把诊断结果写入品牌真相；
