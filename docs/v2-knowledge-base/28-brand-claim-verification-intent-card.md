# 意图卡：AI 品牌描述逐条事实核验与污染预警 V1

状态：Gate A 待用户确认
日期：2026-09-14

## 为什么现在做

首次基线和周期化监测已经获得真实回答，但“出现品牌名称”和“AI 怎样描述品牌”不是同一件事。北京珈程存在已知网络软文污染风险，下一步应把品牌直问回答拆成可追溯主张，逐条判断与批准品牌事实、禁用表达和矛盾规则的关系，再决定是否需要事实澄清、官网页面或外部信源动作。

## 输入

- 已批准的北京珈程品牌真相版本；
- 现有 78 条真实 DeepSeek API 回答及采集上下文；
- 品牌直问与中性问题对象类型；
- 禁用表达、确定性矛盾、官网自述和待核验事实；
- 回答中的引用候选与来源状态。

## 输出

1. 从品牌相关回答中提取逐条主张和原文证据片段；
2. 每条主张分类为：事实一致、事实冲突、仅品牌自述、证据不足、不适用；
3. 命中“13 年、5A、256 位导游、连续五年零投诉”等污染表达时给出明确预警；
4. 关联批准事实 ID、矛盾规则、回答 ID、问题、轮次和引用证据；
5. 汇总不同周期中的重复错误、稳定事实和不确定描述，但不把两次采样夸大为长期趋势；
6. 在验收台按问题和主张下钻，展示“AI 说了什么、依据是什么、为何判定”；
7. 形成下一步动作候选：不行动、补企业事实、修官网、建设可核验信源或进入内容任务书；动作仍按证据门槛决定。

## 自动化边界

- 确定性禁用表达和明确事实矛盾自动判定；
- 语义相近但不能可靠判断的主张只标记“证据不足”，不得硬判真假；
- 不把注册资本、实缴资本或社保人数直接推导为服务质量、接待能力或欺诈结论；
- 不自动抓取新竞品直问，不扩大模型和终端；
- 不生成反驳文章、不发布、不公开指控任何主体；
- 用户只在系统提出高风险事实修订或后续内容/发布动作时做 Yes/No。

## 验收标准

1. 每个判断可反向下钻至不可变回答和品牌事实；
2. 明确命中禁用表达的测试样本必须稳定识别；
3. 无法证明的判断返回“证据不足”，不出现伪造来源；
4. 品牌直问分析不进入自然提及率分母；
5. 租户隔离、幂等、规则版本、失败恢复和审计通过；
6. 页面使用文旅负责人能理解的语言展示风险与建议。

## 非目标

- 不评价实际服务质量或认定虚假宣传；
- 不启动竞品深挖、多模型或 Web/App 采样；
- 不生成、发布或批量分发内容；
- 不把规则判断包装成法律结论。
