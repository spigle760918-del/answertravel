# Web 意图卡：V2 可视化验收台

状态：Gate A-F 已通过并封版
日期：2026-09-14

## 用户问题

业务负责人不具备编程经验，不能长期依赖代码、测试数量和文字描述判断系统是否符合文旅工作方式。现有品牌真相、游客问题和答案采集能力需要尽早形成可看到、可点击、可下钻的网页，让业务歧义在继续开发前暴露。

## 产品定位

本切片建设 AnswerTravel V2 永久 Web 产品外壳和第一条只读验收路径，不制作一次性 Demo。后续基础 GEO 情报、决策、内容和发布模块继续在同一界面架构中增加。

## 本切片输入

- 品牌真相卡及其版本、审核状态、公开范围与质量问题；
- 问题组版本、问题分类、纳入/排除状态和实际配比；
- 观察计划、问题×轮次任务、尝试、失败、token 用量和 DeepSeek API 原始回答；
- 明确隔离并标注为“验收测试数据”的数据库数据集。

## 用户能看到什么

1. **项目概览**：当前是 Alpha、当前品牌空间、已完成模块、尚未具备能力和最近运行状态；
2. **品牌真相**：事实、来源、审核状态、公开范围、冲突与缺口；
3. **游客问题**：固定/探索/触发分组，中性/品牌/竞品/对比类型，实际数量及排除原因；
4. **采集运行**：计划样本、成功、失败、预算停止、重试次数、模型和明确的 `DeepSeek API` 终端；
5. **原始回答下钻**：问题、轮次、回答全文、时间、耗时、token、结束原因和原始证据标识；
6. **限制说明**：尚未计算 GEO 指标、没有引用时不显示虚假引用、API 不代表 Web/App 搜索表现。

## 界面原则

- 全中文文旅业务语言，默认不展示数据库、队列、Schema 等工程术语；
- 任何汇总数字可点击下钻至对应问题、尝试和原始回答；
- 失败、空状态、加载状态和证据不足必须可见，不只展示成功；
- 测试数据始终显示醒目的“验收测试数据”，不得伪装为真实品牌运营结果；
- 桌面浏览器优先，同时保证常用手机宽度可阅读；
- 本切片只读，不包含正式发布、删除或高风险操作。

## 数据与安全边界

- 页面只从 V2 API/数据库读取，不在前端生成业务事实或趋势；
- API Key、数据库地址、原始认证头和内部敏感事实不得返回浏览器；
- 租户隔离继续由数据库 RLS 和服务端上下文保证；
- 生产路径不内置 mock。自动测试 fixture 与验收测试数据必须独立、明确标注；
- 错误页面不得泄漏堆栈、密钥或连接信息。

## 验收场景

1. 用户打开一个本地网页即可看到“验收测试数据”概览，无需运行命令；
2. 从采集计划点击到具体问题，再点击到某轮 DeepSeek API 原始回答；
3. 成功、重试失败、预算停止和无数据状态均使用业务语言正确显示；
4. 中性、品牌、竞品和对比问题清楚分组，不能误解为同一提及率样本；
5. 页面明确显示当前未计算 GEO 指标，不能出现模拟提及率或趋势；
6. 跨租户 URL 或参数无法读取其他品牌数据；
7. 自动化浏览器测试覆盖桌面、手机宽度、下钻链路、错误和敏感信息泄漏；
8. Gate E 必须向用户实际打开网页，由用户基于所见界面回答 Yes/No，不再只凭文字摘要验收界面。

## 非目标

- 不在本切片计算提及率、排名、情感、引用或竞品差距；
- 不导入真实业务品牌资料；
- 不公开部署到域名；
- 不增加编辑、审批、生成文章或发布操作；
- 不替换已完成的 V2 后端模块或建立另一套演示数据库。

## Gate A 后的实施顺序

1. 固定页面信息架构、只读 API 和错误/空状态契约；
2. 选择可持续沿用的 Web 技术形态并记录技术决策，不建立一次性页面；
3. 建立隔离验收数据集，完成概览→问题→运行→原始回答的真实下钻；
4. 完成 API、权限、安全、浏览器、桌面与手机宽度测试；
5. 实际在 Codex 中打开网页给用户验收，通过后再进入基础 GEO 情报切片。

## 2026-09-14 实施与验证证据

- 永久 Web 外壳采用 React + Vite；Fastify 同一 V2 服务提供只读 API 与生产静态文件，没有建立第二套业务系统或一次性 Demo。
- 验收 API 固定读取服务端配置的单一租户，不接受 URL 传入任意租户作为数据上下文；数据库 RLS 保持生效。
- 隔离验收数据集真实完成 DeepSeek API 问题生成和 2 问题 × 2 轮答案采集；页面醒目标注“验收测试数据”，未导入真实品牌资料。
- 页面已实现项目概览、品牌真相、游客问题、采集运行、失败/预算停止和原始回答证据抽屉；未显示提及率、排名、情感、引用或趋势等尚未实现指标。
- 自动测试为 18 个文件、79/79 通过；新增覆盖验收台关闭状态、敏感凭据不返回浏览器、固定租户和跨租户参数无效。
