- 只读识别`www.jiacheng666.com`对应的Nginx站点配置、站点根目录和反向代理关系；
- 只读识别PHP/静态文件/CMS或其他运行技术，不登录CMS、不读取数据库内容；

- 不修改站点文件、Nginx、PHP、数据库、宝塔配置、DNS或证书；
- 不重启或重载Nginx/PHP，不清缓存，不执行CMS升级或插件安装；
- 不读取或输出数据库密码、API密钥、Cookie、会话、私钥、证书私钥或用户数据；
- 不递归输出完整源码，不打包或下载官网文件；
- 不访问后台登录页面，不处理验证码，不尝试获取后台权限；
- 不生成或发布页面内容，不调用DeepSeek，不启动周期监测。
