# 意图卡：品牌个性化事实补充工作台 V1

状态：Gate A-D 已完成，Gate E 待用户验收
日期：2026-09-15

## 授权依据

用户已通过品牌个性化事实采集框架 Gate E，并要求避免过度纠结单一品牌业务细节。本切片把当前品牌剩余“等待事实”行动包合并为一次性总览，不再逐个细节设置验收门。

## 用户问题

品牌负责人如何只看一处就知道哪些主题需要现在补充、哪些可以标记不适用、哪些可以以后再补，而无需在多个零散页面和重复 Gate 之间切换？

## 输入

- 最新不可变优化行动计划；
- 已通过的 `action-fact-intake.v1` 通用框架；
- 当前品牌全部 `waiting_facts` 行动包；
- 已单独封版的退款政策采集快照。

## 输出

1. 一次性展示剩余品牌事实行动包；
2. 每个行动包展示其诊断来源数和品牌专属关注主题；
3. 汇总行动包数、主题数和仍待品牌输入的数量；
4. 统一展示5项证据外壳和三种回答状态；
5. 事实草案、内容生成和发布继续关闭。

## 自动化边界

- AI 自动创建尚未建立的品牌个性化采集快照并保持幂等；
- 同一行动包不重复生成；
- 不要求用户现在提供具体价格、行程或产品服务资料；
- 不调用 DeepSeek，不修改官网，不发布，不对外联系。

## 验收标准

1. “官网价格与行程事实区”和“产品服务颗粒度补充”在同一工作台展示；
2. 21条与20条来源缺口分别保留追溯，不混为同一指标；
3. 两个行动包合计7个个性化主题；
4. 每个主题支持现在提供、不适用、稍后增补；
5. 不产生任何未经品牌确认的事实值；
6. 所有快照不可变、租户隔离、可审计且重复执行不新增重复数据。

## 非目标

- 不逐项收集或批准真实业务资料；
- 不生成内容、FAQ、页面蓝图或结构化数据；
- 不把两个行动包的缺口相加后冒充新的 GEO 指标；
- 不修改历史退款采集快照。

## Gate B-D 实施证据
