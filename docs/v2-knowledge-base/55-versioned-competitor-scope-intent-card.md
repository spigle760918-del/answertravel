# 意图卡：版本化竞争范围与同口径对比 V1

状态：Gate A-F 已完成并封版

日期：2026-09-21

关联决策：`50-final-product-ui-and-implementation-adr.md`、`54-question-centered-analysis-evidence-intent-card.md`

## 1. 为什么要先做这个契约

“竞争对手分析”不是把几个品牌名字放进表格。它必须先回答：这个实体为什么适合与当前品牌放在同一个游客问题下观察，这个关系在哪个区域和时间范围内成立。

没有版本和有效起止时间时，系统只能展示“回答中出现了某实体”，不能宣称它是市场竞争对手。

## 2. 契约目标

### 2.1 范围版本

每个品牌空间的竞争范围是不可变版本，而不是对一个字段的覆盖。一个版本至少包含：

- 版本号、状态、创建时间和确认人；
- 适用品牌实体和品牌真相版本；
- 竞争实体、别名、关系类型和关系状态；
- 重叠的产品/服务、目的地或区域；
- 有效起止日期、证据或说明、资料来源；
- 是否允许进入同口径对比，以及限制原因。

### 2.2 实体关系类型

只使用能被人理解的关系类型：

- `direct_competitor`：在指定产品/服务和区域上直接重叠；
- `alternative`：在该游客决策中可能替代，但不宣称为直接竞争；
- `reference`：用于观察和对照的参考实体，不参与胜负汇总；
- `excluded`：已评估但明确不进入本版对比。

`alternative` 和 `reference` 可以出现在观察证据中，但不能被前端统称为“竞争对手”。

## 3. 同口径对比门禁

只有以下条件同时满足，才能计算品牌与实体的差异：

- 同一个游客问题和问题组版本；
- 同一 AI 平台、模型版本、采集方式、语言、区域和轮次；
- 同一个有效观察时间窗口；
- 对比实体属于当前版本的 `direct_competitor` 或被明确允许的 `alternative`；
- 两方都有可分析的有效回答，失败不当作缺席；
- 指标本身支持对比，例如出现回答数或明确提及；不支持时返回“不适用”。

任何条件不满足时，页面可以展示各自证据，但必须显示“不可比较”及具体原因。

## 4. 页面计划

### 4.1 竞争范围

用户可以查看已确认的范围版本和它的适用条件。本切片不开放无后端契约的编辑、新增和批量导入。

### 4.2 竞争对手分析

按游客问题显示：

- 参与对比的实体和关系类型；
- 品牌与实体各自的有效回答数、明确提及和适用排名；
- 是否可比较、失败数和证据入口；
- 不可比较时的具体原因；
- 与来源证据、原始回答和分析规则的下链。

不展示“竞争力分”、“市场份额”、无问题口径的总排名或自动生成竞品名单。

## 5. 数据契约草案

### `competitor_scope_versions`

- `id`, `tenant_id`, `version`, `status`, `brand_truth_version`;
- `effective_from`, `effective_to`, `region`, `evidence_note`, `source_reference`;
- `confirmed_by`, `confirmed_at`, `created_at`;
- 不可变，不覆盖历史版本。

### `competitor_scope_entities`

- `scope_id`, `tenant_id`, `entity_id`, `name`, `aliases`;
- `relationship_type`, `overlapping_offerings`, `region`, `effective_from`, `effective_to`;
- `status`, `evidence_note`, `source_reference`;
- 实体只能属于某一版本，没有无版本的全局竞品表。

本轮先落实 Zod 读契约、只读仓库和两个诚实状态：“未建立版本”、“版本存在但不可比较”。写操作、导入和竞品直问采样不在本切片。

## 6. 明确不做

- 不把北京珈程或任意固定品牌写进全局规则；
- 不从 AI 回答自动推导竞争关系；
- 不在没有同口径样本时生成胜负、排名或市场份额；
- 不启动竞品直问、新的付费采样或客户官网抓取；
- 不引入 CRM、通用市场情报或广告分析。

## 7. 验收条件

1. 多租户读取只能返回当前会话租户的竞争范围。
2. 历史版本可追溯，不可被新版本覆盖。
3. 未建立范围时页面显示诚实空状态，不出现竞品排名或占位数据。
4. 每条竞对对比均可回到问题、原始回答、分析规则和来源证据。
5. 不可比较时保留具体口径差异，而不是强制输出一个数值。
6. 用户 Gate E 确认前，不制作服务器候选和不切换生产流量。
