# 意图卡：北京珈程官网结构修复蓝图 V1

状态：Gate A-D 本地通过，待生产部署与 Gate E
日期：2026-09-17

## 为什么现在做

生产官网只读诊断已形成5个页面的不可变证据，确认页面可访问且主体、许可、备案和产品基础信息可读取，同时发现JSON-LD、meta description、canonical、H1和图片alt五类结构缺口。下一步应先把缺口转换成可执行、可验收、可回滚的修复蓝图，而不是直接修改官网或生成宣传内容。

## 输入

- 最新`website-diagnosis.v1`生产快照及5个页面的内容哈希；
- 已批准品牌真相、公开范围、禁用表达和资质可信证据蓝图；
- 已封版优化行动计划中的“官网价格与行程事实区”行动包；
- 当前官网只读可见的页面结构，不读取后台、不要求登录。

## 输出

1. 按页面列出缺失的meta description、canonical、H1、JSON-LD和图片alt，不把全站汇总数字直接当成修改指令；
2. 生成不超过3个实施批次：全站模板基础、主体与资质事实、产品与行程事实；
3. 每个任务明确证据引用、建议字段、允许使用的已批准事实、禁止表达、风险、回滚点和验收方法；
4. JSON-LD只生成字段蓝图与候选类型，不生成无法证明的评分、销量、价格有效性、资质等级或评论；
5. 标出哪些任务可以由技术人员直接实现，哪些仍需品牌提供当前价格、行程或服务事实；
6. 形成不可变、租户隔离、可幂等复算的F4修复蓝图，并接入验收台。

## 自动化边界

- AI自动完成页面级差异映射、任务合并、优先级、验收规则和回滚说明；
- 只复用现有官网快照与已批准事实，不新增外部抓取范围，不调用DeepSeek；
- 不连接宝塔后台、CMS或网站服务器，不修改HTML、模板、Nginx、DNS或数据库；
- 不生成或发布文章、FAQ、评论、营销承诺或对外消息；
- `implementationAuthorized`与`publicationAuthorized`固定为`false`；
- 任何真实官网修改必须在蓝图验收后单独获得明确授权，并先备份、预览和定义回滚。

## 验收标准

1. 5类结构缺口均能追溯到具体页面和诊断快照；
2. 同一模板问题不会被拆成大量重复任务；
3. 已批准事实、官网自述、待补事实和禁止表达清晰分层；
4. 每个任务具备可执行验收和回滚方式；
5. 缺少当前业务事实时明确显示“等待事实”，不由AI补写；
6. 重复生成保持幂等，不覆盖历史蓝图；
7. 页面以业务语言展示“为什么改、改什么、暂时不能改什么”。

## 非目标

- 不实施官网改造或发布；
- 不承诺修复后提升AI提及率、引用率、SEO排名或收录；
- 不扩展到竞品网站、全站爬取、性能压测或搜索引擎数据；
- 不启动周期监测、多模型采样或任何付费API调用。
