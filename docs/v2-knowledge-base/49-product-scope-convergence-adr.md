# ADR：AnswerTravel 产品范围收敛与 GEOFlow 设计复用边界

状态：已确认，进入界面 Gate B 预览

日期：2026-09-18

## 1. 决策

AnswerTravel 保留自身产品内核，只服务于以下闭环：

`GEO 观察 → 原始证据 → 诊断 → 决策 → 行动 → 复测`

GEOFlow 固定版本 `abcc638887dd35f508a59815f01ed42bc4415a09` 仅作为设计系统、页面母版和成熟交互参考，不再作为 AnswerTravel 的功能范围或一级栏目清单。

## 2. 明确舍弃的产品范围

以下能力不进入 AnswerTravel，也不预留客户可见入口、占位栏目或“后期扩展”接口：

- 通用 CMS、建站系统和主题装修；
- 与 GEO 决策无关的通用内容工厂；
- 海量关键词库、标题库和素材库；
- 通用多站群发布与 SEO 站群运营；
- 网站流量归因、广告归因和通用 Web Analytics；
- 表单线索、CRM、销售漏斗和订单转化；
- 广告位、会员、门户用户、系统升级等 GEOFlow 网站后台能力。

若 GEO 行动确实需要生成文章、FAQ、页面结构、结构化数据或发布修复，这些产物只作为某次诊断的受控行动存在，必须关联证据、批准、回执与复测；不得扩张成独立 CMS 或内容生产平台。

## 3. 保留的产品能力

- AI 工作台：自然语言任务入口，完成意图理解、Skill 匹配、权限/预算校验、计划预览、确认、执行和结果解释；
- 观察：问题组、模型/终端、计划、采样、失败和成本；
- 证据：不可变回答、引用、来源快照、采集上下文和事实等级；
- 诊断：AI 可见性、品牌/竞品差距、网站与信源缺口、置信度和替代解释；
- 决策：根因、优先级、可选动作、不行动选项和风险；
- 行动：由诊断产生的受控任务、审批、执行、回执和回滚；
- 复测：同口径问题组、观察周期、变化检测和谨慎归因；
- 品牌真相：作为全部观察、诊断和行动的事实基础；
- 平台管理：租户、成员、权限、Provider、预算、Skill/Prompt 版本和审计。

## 4. 界面信息架构

客户产品一级导航固定为：

1. AI 工作台
2. 总览
3. 观察
4. 证据
5. 诊断
6. 决策与行动
7. 复测
8. 品牌真相

平台管理员通过独立入口管理组织、权限、模型服务、Skill/Prompt、预算和审计；工程部署、迁移、备份、CI 和服务器门禁不进入客户主界面。

## 5. GEOFlow 复用范围

允许直接对齐：

- 左侧导航、顶栏、页面标题与主操作布局；
- 白色/浅灰高密度后台、蓝色主操作和克制装饰；
- 筛选、表格、详情抽屉、状态、步骤、确认弹窗、Toast、空状态和响应式行为；
- AI 工作台的对话、计划预览、审批和执行进度交互；
- 列表—详情—证据下钻—行动的成熟操作模式。

禁止因为 GEOFlow 原项目存在某页面，就为 AnswerTravel 创建同名空功能。

## 6. 门禁

- 本 ADR 覆盖 `47` 和 `48` 中“完整保留 GEOFlow 原始一级导航及全部页面”的旧要求；
- 先输出完整可交互界面供用户逐页确认；
- Gate E 前不得修改运行代码、部署生产或连接客户官网；
- 实施阶段只允许映射真实 AnswerTravel API，不得使用模拟指标填满页面。
