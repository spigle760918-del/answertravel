# 意图卡：阿里云隔离预发布准备 V1

状态：Gate A-D 已完成，Gate E 待用户验收
日期：2026-09-15

## 授权依据

用户已通过 Alpha 上线就绪总览 Gate E，并确认继续进入云端预发布准备。该授权仅允许生成、验证和封装部署资产，不允许直接修改阿里云现有业务。

## 用户价值

把已验证的 V2 变成可在宝塔服务器隔离部署的生产构建与配置包，尽量减少业务负责人需要理解或操作的技术细节。

## 输出

1. Node.js 24 可运行的后端生产构建；
2. Web 生产静态文件；
3. 仅回环监听的环境变量契约；
4. 独立域名 Nginx 反向代理模板；
5. API 与 Worker 独立进程启动契约；
6. 数据库迁移角色与运行角色分离说明；
7. 备份、恢复、健康检查和回滚清单；
8. 不包含密钥的可审阅发布包。

## 隔离边界

- 不覆盖、重启或修改现有 PHP 站点、MySQL、Nginx 主配置和宝塔面板；
- V2 API 默认只监听 `127.0.0.1`；
- PostgreSQL、Redis 不开放公网端口；
- DeepSeek Key 只通过服务器密钥配置注入；
- 迁移账号不得交给 API 或 Worker；
- 本切片不执行域名解析、证书签发或服务器安装。

## 验收标准

- `npm run build:alpha` 在 Node.js 24 下生成可运行产物；
- 配置模板不含真实密码、API Key、租户 ID 或服务器凭据；
- 生产启动无需 `tsx`；
- Nginx 模板只转发到回环端口并保留健康检查；
- 发布清单明确备份、恢复、回滚和现有业务保护步骤；
- Linux CI 验证构建与契约。

## 非目标

- 不在本切片中宣称云端运行通过；
- 不绕过宝塔安全策略；
- 不自动发布内容或启用长期计费监测；
- 不扩展多模型或多账号渠道。

## Gate B-D 实施证据

- 新增严格 Node.js 24 的 `build:alpha`，生成后端 `dist/` 与前端 `web-dist/`；生产 API、Worker 和迁移入口均使用编译后 JavaScript，不依赖 `tsx`。
- 新增阿里云/宝塔环境模板、独立域名 Nginx 回环反向代理模板、部署顺序、备份恢复和回滚清单。
- 环境模板仅包含占位符，不含真实数据库密码、DeepSeek Key、租户 ID 或服务器登录凭据。
- GitHub Linux CI 已增加生产构建门禁。
- Node.js 24 本地生产构建通过；完整验证33个测试文件、140/140通过，PostgreSQL冷备恢复、Redis AOF恢复和Web生产构建通过。
- 本次未连接或修改阿里云，未修改域名、证书、Nginx、数据库、Redis或现有业务。

## Gate E 待验收

用户只需确认：预发布方案是否应继续坚持“独立目录、独立域名、回环端口、权限分离、可回滚、不影响现有业务”的路线。确认后才进入真实服务器变更准备。
