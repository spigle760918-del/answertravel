# 意图卡：退款、取消与履约政策事实采集 V1

状态：Gate A-D 已完成，Gate E 待用户验收
日期：2026-09-15

## 授权依据

用户已通过资质来源核验 Gate E，并要求系统按行动计划自动进入下一步。优化行动计划已将“退款、取消与履约政策确认”列为第二行动包。本切片只准备事实采集结构，不产生公开政策，因此 Gate A 继承授权。

## 用户问题

为了让 AI 能准确回答“取消会损失多少、多久退款、什么情况例外”，旅行社最少需要一次性补充哪些真实合同事实，系统如何避免按行业惯例猜测？

## 输入

- 最新不可变 `optimization-action-plan.v1`；
- 退款政策行动包关联的 7 条证据缺口；
- 当前批准品牌真相、公开范围和禁用表达；
- 高风险公开承诺必须人工确认的规则。

## 输出

1. 一张最小事实采集卡，将重复问题合并为少量业务字段；
2. 字段覆盖：适用产品/合同版本、取消时间点、游客承担费用、已发生费用、退款办理时限、例外情形、责任与凭证；
3. 每个字段要求事实值、依据材料、适用范围、生效时间和公开范围；
4. 完整性检查与矛盾检查规则；
5. “有现行政策”和“当前暂无统一政策”两条诚实路径；
6. 只生成待补资料状态，不生成政策正文或公开承诺。

## 自动化边界

- AI 自动去重、组织字段、检查缺漏和冲突；
- 退款比例、扣费项目、办理天数和例外不得由行业惯例或模型补全；
- 未取得现行合同或实际执行规则时，状态固定为“等待真实资料”；
- 用户可选择“暂无统一政策”，系统将建议仅公开“以签署合同为准”，但不会把该建议发布；
- 不上传、读取或处理用户尚未提供的合同文件；
- 不调用 DeepSeek，不修改官网，不发布，不对外联系。

## 验收标准

1. 7 条证据缺口全部映射到采集字段且不重复询问；
2. 采集卡不含任何推断的比例、金额或时限；
3. 缺少依据材料时不能进入待审核政策摘要；
4. “暂无统一政策”是合法输入，不强迫品牌虚构统一规则；
5. 公开范围与内部合同内容分开；
6. `summaryDraftAuthorized=false`、`publicationAuthorized=false`。

## 非目标

- 不代替合同、法务或业务负责人制定退款政策；
- 不判断现行条款是否合法或是否公平；
- 不生成客服话术、FAQ 正文或官网页面；
- 不发布任何金额、比例、期限或责任承诺。
