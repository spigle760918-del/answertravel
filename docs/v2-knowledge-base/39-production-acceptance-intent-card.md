# 意图卡：阿里云生产实例验收状态 V1

状态：Gate A-D 实施中
日期：2026-09-16

## 用户价值

让公网验收台展示当前生产实例的真实部署状态，避免继续显示部署前的 `blocked-by-host-policy` 和“HTTPS 未验收”，也避免新服务器自动继承旧服务器的通过状态。

## 输入与证据

- 用户返回的阿里云 Docker Compose、数据库、Redis、API、Worker 运行结果；
- `https://geo.21y.com/`、验收接口和就绪接口的 HTTP 200 结果；
- 独立浏览器对公网首页的真实渲染检查。

## 输出

- 验收台的“阿里云原生运行验证”和“域名与 HTTPS 预发布”由当前实例的显式证据配置决定；
- 未配置证据时继续显示阻塞或待完成；
- 已配置时展示证据摘要，不显示密钥、密码或连接串。

## 边界

- 不把 DeepSeek 采样、周期监测、云端备份恢复或日志告警标记为完成；
- 不创建观察计划，不调用模型，不开放发布权限；
- 不把 API 结果表述为 Web/App 搜索表现；
- 更换服务器后必须重新验收，不复用旧实例状态。

## 验收标准

- 无部署证据配置时现有测试仍保持阻塞；
- 同时提供两项证据时，对应状态为 `ready` 且阻塞数减少；
- 公网首页仍能显示北京珈程、品牌真相 V2 和 20 条问题；
- 已批准问题组不得继续显示为“问题草案”或“尚未批准”；
- Worker 保持空闲运行，真实回答、观察计划和周期计划仍为 0。
