## Phase 1 内部实现选择

- 2026-09-13：使用 Fastify、pg、Zod、BullMQ、ioredis；依赖精确版本与完整依赖树以 `v2/package.json`、`v2/package-lock.json` 为准。
- 在 V2 忽略目录内安装官方 Node.js 24.21.0 便携运行时，不替换系统 Node.js 25；本地编译与基础测试已有证据，数据库与队列运行验证待完成。
- 以上属于已确认架构内的技术实施，不扩大 Phase 1 或 Alpha 产品范围。
- 2026-09-13：在本地无 Docker/WSL 的情况下，采用固定版本的独立 PostgreSQL 与 Redis Windows 测试进程，随机回环端口、独立临时数据目录，结束后关闭本次进程。Linux CI/阿里云验证仍单列，不把 Windows 结果冒充 Linux 结果。
- 2026-09-14：纠正协作执行偏差。此前曾在本地已具备 Git 仓库、凭据和网络能力时，仍要求用户手动推送并回报“已推送”；该做法违反 AI 自动推进原则。今后请求人工操作前必须证明存在 AI 无法跨越的真实阻塞，并把用户动作压缩到最小范围。
