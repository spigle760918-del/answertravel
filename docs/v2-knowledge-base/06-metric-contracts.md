# AnswerTravel V2 核心指标契约草案

状态：原则已确认；计算细节随对应模块契约逐项固化

## 通用要求

任何指标必须同时携带：品牌/竞品、问题组版本、模型、终端、模型版本、地区/语言、时间窗、有效样本量、失败样本量、采样轮次、算法版本和置信信息。

## 初始指标

### 品牌提及率

`提及目标品牌或确认别名的有效回答数 / 有效回答总数`

不得混入无正文、失败、演示或不同问题组的记录。别名规则必须版本化。

### 推荐/出现排名

仅在回答存在明确候选列表、推荐顺序或可审计出现顺序时计算。叙述性文章没有可比排名时返回 `不适用`，不能强行赋值。

### 情感与品牌描述

优先记录主张级标签：正向、负向、中性、混合、不确定，并保存对应文本证据。情感模型和阈值必须版本化；严重风险需要人工复核。

### 引用

至少区分：

- `selected`：出现在可见来源/引用列表；
- `absorbed`：来源内容与答案存在可复核的事实或语义吸收；
- `embedded_link`：仅在正文出现链接；
- `retrieval_candidate`：检索候选但无法证明被答案使用。

### 竞品差距

只在同一问题组、模型、终端、区域、时间窗和采样规则下比较。展示绝对差值、样本量和不确定性，不只展示百分比。

### 发布后变化

必须绑定基线问题组、干预内容/页面、发布时间、观察窗口和对照组。默认表述为“观察到的变化”或“与干预一致的关联”；只有满足预先定义的实验条件时才使用因果措辞。
