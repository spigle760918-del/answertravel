## 隔离边界

- 不覆盖、重启或修改现有 PHP 站点、MySQL、Nginx 主配置和宝塔面板；
- V2 API 默认只监听 `127.0.0.1`；
- PostgreSQL、Redis 不开放公网端口；
- DeepSeek Key 只通过服务器密钥配置注入；
- 迁移账号不得交给 API 或 Worker；
- 本切片不执行域名解析、证书签发或服务器安装。

## 验收标准

- `npm run build:alpha` 在 Node.js 24 下生成可运行产物；
- 配置模板不含真实密码、API Key、租户 ID 或服务器凭据；
- 生产启动无需 `tsx`；
- Nginx 模板只转发到回环端口并保留健康检查；
- 发布清单明确备份、恢复、回滚和现有业务保护步骤；
- Linux CI 验证构建与契约。

## 非目标

- 不在本切片中宣称云端运行通过；
- 不绕过宝塔安全策略；
- 不自动发布内容或启用长期计费监测；
- 不扩展多模型或多账号渠道。

- 用户已将 `/www/swap` 扩展至4 GiB并启用，当前使用量接近0，且已写入 `/etc/fstab` 持久化。

- 这只解除 swap 风险门槛，不代表容器已经启动、数据库已迁移、HTTPS已配置或公网已上线。
