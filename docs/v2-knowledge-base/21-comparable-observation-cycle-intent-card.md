# 意图卡：同口径样本扩充与可比较周期 V1

状态：Gate A-D 已完成，Gate E 待用户验收  
日期：2026-09-14

## 为什么现在做

当前真实证据只有 4 条中性有效回答和 1 个观察周期，品牌与竞品均为零自然提及。该样本不足以判断谁领先，也不足以决定内容方向或启动竞对直问。系统下一步应先自动补齐最小可比较证据，而不是让文旅负责人凭感觉选题或研究竞品。

## 用户确认的问题

是否允许系统在固定口径下追加真实 DeepSeek API 中性采样，形成至少 6 条有效回答和 2 个可比较观察周期，并在达到门槛后自动重新运行差距诊断？

本 Gate A 的 Yes 同时代表对本切片内最小追加 API 消耗的明确授权；未获得 Yes 前不调用 API、不产生新增费用。

业务确认：2026-09-14，用户明确回复“确认，进入下一步”，授权本切片最小范围真实 DeepSeek API 追加采样。

## 本切片输入

- 已批准的问题组版本及其中性基准问题；
- 已存在的 4 条中性有效回答、采集尝试和不可变原始证据；
- 固定的 DeepSeek 模型、API 终端、区域、系统提示、采样参数和规则版本；
- 品牌与竞品实体版本及当前差距诊断快照；
- 预算上限、重试规则、停止条件和密钥可用状态。

## 本切片输出

1. **可比较采样计划**：明确补采问题、轮次、预计请求数、预算上限和停止条件；
2. **第二观察周期**：时间边界清晰，问题、模型、终端、区域和规则与基线同口径；
3. **不可变新增证据**：每次尝试、原始回答、失败状态、模型版本、token 和费用估算均可追溯；
4. **可比较性判定**：满足或不满足，并逐项说明发生变化的条件；
5. **自动复诊结果**：达到门槛后重新运行差距诊断，仍不足则继续返回证据不足；
6. **下一动作建议**：只在可靠证据形成后建议继续观察、内容/页面/信源动作，或申请竞对深挖。

## 固定业务规则

- 最低门槛为至少 6 条中性有效回答和至少 2 个可比较观察周期；最低门槛只允许系统开始判断，不等于自动证明竞争差距。
- 两个周期必须保持问题、模型、终端、区域、规则版本和关键采样参数同口径；不可比时不得拼接成趋势。
- 本切片只追加中性问题采样，不生成“竞对旅行社怎么样”等竞对直问，不让品牌/竞品直问污染自然提及率。
- 失败、超时、截断和无效回答保留为原始证据，不隐藏，不计入有效样本分母。
- 达到门槛后自动复算，不要求用户手工读数据；若品牌与竞品仍均为零提及，返回“未观察到差距/证据仍弱”，不能强行生成内容任务。
- 只有出现可靠竞品领先且现有证据无法解释原因时，才创建竞对深挖建议；真正启动隔离的竞对直问仍需新的 Yes/No。
- 网站诊断尚未接入时继续显示“证据未接入”，不能把缺失证据解释为网站没有问题。
- 本切片不使用本次差距诊断 Gate E 的 Yes 作为新增采样授权。

## AI 与人的分工

- AI 自动选择满足同口径要求的最小补采方案，入队、重试、保存证据、检查可比性并复诊。
- 人只需在 Gate A 对本轮最小真实 API 消耗回答 Yes/No；遇到密钥失效、预算越界或业务口径改变时再介入。
- 自治等级为 A0 观察和 A1 建议；不自动发布内容，不自动扩大采样范围，不自动进入竞对直问。

## 验收场景

1. 未获 Gate A Yes 时，系统不创建真实采样任务，也不调用 DeepSeek API。
2. 获批后只按计划产生最小请求；重复执行保持幂等，不重复消耗预算。
3. 新旧周期口径一致时标为“可比较”；任一关键维度改变时标为“不完全可比较”并阻止趋势结论。
4. 有效回答不足 6 条或有效周期不足 2 个时，复诊继续返回证据不足，不生成竞争胜负。
5. 达到最低门槛后自动复诊，所有结论可下钻到原始回答和采集上下文。
6. 品牌与竞品仍无自然提及时，系统显示未观察到领先者，不为填满页面而生成内容方向。
7. 发现可靠竞品领先但原因不清时，只生成隔离深挖建议、预算和停止条件，等待新的 Yes/No。
8. 数据库、队列或 Provider 失败后能够恢复；失败任务可追溯，不覆盖历史证据。

## 非目标

- 不接入新的 AI 模型、Web/App 终端或真实网站爬取；
- 不执行竞对直问、热点问题、品牌诱导问题或无限轮采样；
- 不生成文章、选择范文、发布内容或宣称 GEO 提升；
- 不因达到 6 条回答和 2 个周期就自动宣称统计显著或因果成立；
- 不改变已确认的指标口径、V2 架构或 DeepSeek API 与 Web/App 分离原则。

## Gate A 通过后的实施顺序

1. 固定采样计划、周期、可比较性和预算契约；
2. 先补充未授权、幂等、预算越界、失败恢复和不可比周期测试；
3. 创建最小追加采样任务，保存真实不可变证据；
4. 自动形成第二观察周期并运行可比较性检查；
5. 达到门槛后自动重新运行差距诊断；
6. 完成测试、浏览器验收与 Gate E；
7. Gate F 更新知识库，再决定是否继续观察或提出竞对深挖审批。
