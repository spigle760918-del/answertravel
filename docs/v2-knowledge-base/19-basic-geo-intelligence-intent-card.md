# 意图卡：品牌与竞品基础 GEO 情报 V1

状态：Gate A 待用户确认
日期：2026-09-14

## 用户问题

文旅负责人需要知道：在同一批游客问题、模型、终端、区域、时间窗和轮次下，AI 是否提及品牌与竞品、如何描述各方、是否存在明确推荐顺序，以及差距是否足以触发行动。系统必须先生成可复算、可下钻的事实，再进入竞对深挖和内容决策。

## 本切片输入

- 已批准的品牌真相卡：正式名称、别名、产品/服务事实和禁用表达；
- 已批准的问题组，且明确区分中性品类、品牌直问、竞品直问、品牌对比；
- 不可变原始回答、采集上下文、尝试和引用/信源证据；
- 已确认的竞品名称、别名与实体边界；
- 版本化分析规则与人工标注评测样本。

## 本切片输出

1. **实体提及事实**：品牌/竞品是否被明确提及、出现位置、原文片段、别名命中和是否可能歧义；
2. **条件化排名事实**：仅在回答存在明确列表、推荐顺序或可验证位置时记录名次，否则为 `不适用`；
3. **主张级描述与情感**：把回答拆成对具体品牌的可追溯主张，区分正向、负向、中性、混合和 `不确定`；
4. **同口径对比快照**：按问题类型、模型、终端、区域、时间窗和轮次分组，显示样本量、成功率、品牌/竞品提及率、适用排名和主张分布；
5. **证据不足与质量状态**：样本不足、实体歧义、解析失败、模型波动和不可比较必须显式显示；
6. 验收台中的“指标 → 样本 → 原始回答 → 引用/信源”完整下钻。

## 指标口径

- 中性品类问题的品牌自然提及率与品牌/竞品直问结果分开计算，不得混合。
- 提及率分母是同一口径下成功且可分析的回答；失败、预算停止和解析失败单独显示，不悄悄丢弃。
- 排名只在明确有序结构中适用；普通叙述、并列出现或模型未推荐时返回 `不适用`。
- 情感针对“品牌主张”而非整篇回答；没有足够上下文时返回 `不确定`。
- 所有汇总必须保留样本量、时间范围、模型、终端、问题组版本和分析规则版本。
- 本切片报告观察到的差异，不宣称内容或运营动作造成因果提升。

## AI 与人的分工

- AI 自动完成实体候选识别、主张切分、排名适用性判断、情感候选和汇总计算。
- 确定性规则负责名称/别名命中、分母、分组和复算；AI 输出必须经过 Schema、证据引用和质量门禁。
- 人不逐条分析回答；只处理品牌/竞品实体歧义、低置信度例外和会影响业务结论的少量 Yes/No。
- 本切片自治等级为 A0 观察与 A1 建议，不执行内容生成或发布。

## 竞对深挖触发接口

本切片只给出是否建议深挖及原因，不立即无限追加采样。候选触发条件：

- 同口径下品牌连续有效周期落后；
- 竞品主张优势明确但首轮样本无法解释来源；
- 竞品被高频推荐或出现可验证排名优势；
- 样本或置信度不足，需要先扩样而不是下结论。

触发后由下一独立切片生成“竞对怎么样/靠谱吗/适合谁/优缺点/与品牌对比”等问题组，且不污染中性主监测指标。

## 验收场景

1. 中性问题未出现品牌时记录零提及；品牌直问中出现品牌不计入自然提及率。
2. 同一句出现品牌和竞品时分别保存证据片段，不按关键词数量决定胜负。
3. 有序推荐列表可记录排名；并列、普通叙述和无推荐答案均返回 `不适用`。
4. 同一回答包含优点和风险时形成多个主张，可为混合分布，不强制整篇正负面。
5. 品牌别名歧义、样本不足或解析失败显示 `不确定/证据不足`，并允许下钻原因。
6. 跨租户不可见，历史分析不可覆盖，同一规则重复运行保持幂等。
7. 自动评测覆盖确定性样例、边界样例、失败样例和人工金标；页面不泄漏密钥或内部敏感信息。
8. Gate E 用户实际查看品牌/竞品对比、样本量、`不适用` 排名和原始证据后 Yes/No。

## 非目标

- 不在本切片自动生成竞对深挖问题或追加采样；
- 不决定内容选题、不生成文章、不发布；
- 不计算未经验证的内容吸收、引用影响或因果归因；
- 不将 DeepSeek API 结果泛化为 DeepSeek Web/App 或其他模型表现；
- 不导入真实品牌资料，除非用户在后续独立品牌资料导入门禁中明确确认。

## 通过 Gate A 后的实施顺序

1. 固定实体提及、排名适用性、品牌主张、分析运行和对比快照契约；
2. 建立确定性规则基线与人工金标评测集，再引入受约束 AI 分类；
3. 完成原始回答到事实、汇总和证据下钻的最小链路；
4. 扩展验收台展示同口径对比、样本质量和不适用/不确定状态；
5. 完成租户、不可变、幂等、失败、评测、浏览器和安全测试；
6. Gate E 通过后，再进入竞对深挖决策切片。
