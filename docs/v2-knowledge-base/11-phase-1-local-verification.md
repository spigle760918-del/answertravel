| 业务要求 | 实测结果 |
| --- | --- |
| 品牌数据不能串用 | 不同品牌空间相互不可见，越权写入失败 |
| 原始回答不能被改写 | 证据与审计的修改、删除和整表清空均被拒绝 |
| 重复任务不重复计算事实 | 并发重复请求和再次投递只保留同一证据与审计 |
| 每条证据都有操作记录 | 证据与审计同时提交；任一失败则回滚 |
| 临时故障可以恢复 | 任务失败后重试成功；不支持的任务版本明确失败 |
| 服务故障不能显示正常 | 就绪检查正确区分可用、不可用及危险数据库账号 |
| 备份可恢复 | 从数据库冷备份读回相同证据哈希和审计 |
| 队列重启不丢待处理任务 | 强制结束独立 Redis 进程后，从 AOF 恢复等待任务 |
