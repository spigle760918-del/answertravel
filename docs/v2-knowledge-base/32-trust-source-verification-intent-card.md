## 用户问题

哪些资质来源已经被系统独立访问并保存，哪些只能证明品牌或平台当时展示了什么，哪些仍因官方站点访问限制而不能核验？

## 输入

- 最新不可变 `trust-evidence-blueprint.v1`；
- 蓝图中的三项补证任务；
- 精确允许访问的公开网址及安全抓取器；
- 已批准品牌真相和禁用表达。

## 输出

1. 四类只读访问记录：国家企业信用信息入口、欣欣旅行社认证页、品牌官网、工信部备案入口；
2. 每条记录保存精确 URL、访问状态、HTTP 状态、标题、正文摘要、内容哈希、抓取时间和错误码；
3. 从成功快照中只提取确定性命中，不把页面自述升级为官方事实；
4. 将补证任务标为“已取得平台快照”“仍需官方原始查询”“仍需域名主体关联材料”；
5. 验收台用业务语言展示成功、仅自述和来源阻断三种状态。

## 自动化边界

- 仅允许访问固定白名单中的四个 HTTPS 入口；阻止私网、凭据 URL、危险重定向、超限正文和非文本响应；
- 不登录、不提交搜索表单、不处理或绕过验证码、不联系任何机构；
- 欣欣页面只证明该平台在抓取时展示的主体、许可证和业务范围；
- 官网备案号只属于官网自述，未经过工信部查询时不得表述为已完成主体关联；
- 官方入口访问失败或返回 5xx 时记录 `来源阻断`，不得用用户资料补成独立快照；
- 不调用 DeepSeek，不新增竞品直问，不修改或发布官网。

## 验收标准

1. 每个访问目标均有不可变、租户隔离、可幂等复算的结果；
2. 成功快照必须有 SHA-256，失败结果必须有错误码；
3. 欣欣精确页面同时命中公司名称、许可证号与业务范围后，才能解决对应平台补证任务；
4. 官网备案号不自动解决域名主体关联任务；
5. 官方入口被阻断时如实保留待办；
6. `publicationAuthorized=false`，没有任何线上修改或发布动作。

## 非目标

- 不取得需要登录、验证码或人工身份验证的官方查询结果；
- 不把第三方平台认证等同于政府许可系统核验；
- 不生成官网正文或结构化数据发布稿；
- 不对品牌真实性、服务质量或法律状态作超出证据的结论。
